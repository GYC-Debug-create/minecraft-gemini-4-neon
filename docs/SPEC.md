## 1. 产品定义

做一款**原创**的第一人称体素生存沙盒游戏，类型参照“方块挖掘 + 合成 + 生存”这一品类：玩家在程序生成的方块世界里采集、合成工具、建造、度过危险的夜晚。

体验目标：**玩法循环和手感接近该品类的成熟作品的“生存初期”**——出生 → 撸树 → 工作台 → 木镐 → 石器 → 挖矿炼铁 → 搭庇护所熬过第一夜 → 种田/养殖维持饥饿。不追求后期内容。

### 原创性约束（硬性）
- 游戏名、方块/物品/生物名称、贴图、音效、UI 外观、Logo **全部原创**，不使用、不模仿任何现有商业游戏的素材和标志性设计（例如不要出现绿色会爆炸的苦力怕式生物、末影人式生物）。
- 机制层面使用品类通用玩法（方块世界、合成网格、熔炉、昼夜、饥饿）是可以的。
- 所有贴图在运行时用 Canvas 程序化生成（16×16 像素风），音效用 WebAudio 合成。**不下载任何外部美术/音频资源。**

## 2. 技术栈（固定，不得更换）

- TypeScript（strict）+ Vite
- 渲染：Three.js（只用它做渲染，不引入其他游戏引擎、物理引擎）
- 地形生成与网格构建放在 **Web Worker**
- 存档：IndexedDB
- 测试：Vitest（纯逻辑单元测试）+ Playwright（冒烟测试：启动、进入世界、无控制台报错、截图）
- 命令：`npm run dev` / `npm run build` / `npm test` / `npm run e2e` 必须始终可用
- Node 用本机已装的 LTS 版本（≥18），在 PROGRESS.md 记下版本号；项目目录没有 git 仓库就先 `git init`
- **无头浏览器的 WebGL**：Playwright 用 Chromium，启动参数加 `--use-gl=angle --use-angle=swiftshader`（或当前版本等效的软件渲染参数），确保无头模式下能出画面、能截图
- **测试接口**：无头环境无法使用鼠标锁定，必须在开发/测试构建里暴露 `window.__game` 调试接口，供 e2e 脚本驱动游戏：设置朝向、模拟按键、执行挖/放/合成/打开容器、传送、设定出生点、加速时间、读取玩家状态与背包。**这些接口只能模拟玩家的正常操作，不能直接往背包里塞物品**（例外：单元测试里构造场景可以）

### 默认键位（直接采用，无需确认）
WASD 移动、空格跳/上浮、Shift 潜行、Ctrl 或双击 W 奔跑、左键挖/攻击、右键放置/使用、1–9 和滚轮切换快捷栏、E 背包、Q 丢弃、Esc 暂停、F3 调试面板、F2 截图（可选）

## 3. 功能范围

### 3.1 必须实现（In Scope）

**世界**
- 区块化无限地形（区块 16×16，世界高度 ≥128），按种子确定性生成（同种子同世界，需有单元测试）
- 群系：平原、森林、沙漠、雪原、海洋/沙滩、山地，过渡自然
- 洞穴（3D 噪声）、矿石按深度分布：煤、铁、金、一种稀有宝石
- 树木（至少 2 种）、草/花等装饰、沙/砾石受重力下落
- 水：可游泳、半透明、简单流动（源头 + 有限扩散即可）
- 村庄（只有建筑，没有村民）：在平原、沙漠、雪原群系里稀疏生成；由 4～8 栋原创风格的小房子、一条土路、一两块农田（已长着作物）、一口井组成，建材随群系变化
  - 每栋房子随机摆放床、工作台、熔炉中的若干件；整个村庄至少有一个箱子，箱子按战利品表随机放入物品（面包、种子、铁锭、木/石工具、偶尔有铁盔甲）
  - 建筑能跨区块，按种子确定性生成（要有单元测试）；适配地形起伏，不悬空、不埋进山里
  - 箱子的战利品只在第一次打开时生成，之后按普通箱子存档
- 光照：天空光 + 方块光（火把）的传播与衰减，放置/破坏方块后增量更新
- 昼夜循环（一天约 20 分钟），太阳/月亮、日出日落天空渐变、云、与天空颜色一致的雾

**玩家**
- 走、跑、跳、潜行（潜行不掉落边缘）、游泳、AABB 碰撞、摔落伤害
- 生命、饥饿、氧气；饥饿影响回血和奔跑；死亡掉落物品、重生
- 第一人称手部/手持物品渲染，行走镜头晃动，受伤红屏闪烁

**交互**
- DDA 射线拾取、方块描边高亮、挖掘进度裂纹、破坏粒子
- 挖掘时间由方块硬度 × 工具类型/等级决定；错误工具挖不出掉落物（如徒手挖石头）
- 掉落物实体：弹出、旋转、自动拾取、合并
- 放置方块不能放进玩家身体里

**物品与合成**
- 快捷栏 9 格 + 背包 27 格，堆叠上限 64，工具不堆叠且有耐久
- 拖拽、右键拆半、Shift 快速转移
- 背包内 2×2 合成；工作台 3×3 合成（有序配方 + 无序配方）
- 熔炉：燃料 + 冶炼进度 + 产出槽
- 箱子存储
- 工具：木/石/铁/宝石 四档 × 镐、斧、锹、剑、锄；弓 + 箭（蓄力越久射得越远越疼）
- 盔甲：皮革、铁（减伤）
- 火把、床（跳过夜晚 + 设置重生点）、门、梯子
- 农业：锄地、种子、作物分阶段生长、收获、面包
- 食物：生/熟肉、苹果、面包

**生物**
- 被动生物 2～3 种（原创外形），掉落肉/皮/毛等
- 敌对生物 3 种，用通用奇幻题材但**像素外形原创**（不要照搬任何现有游戏的配色和造型）：
  - 僵尸：近战追击，白天在阳光下燃烧，可破坏木门（可选）
  - 骷髅：持弓远程，保持距离射击，箭矢为可见的抛物线投射物，白天在阳光下燃烧
  - 巨型蜘蛛：会爬墙，白天中立、夜晚敌对
  - 共同规则：只在低光照处刷新，掉落对应材料（腐肉、骨头/箭、蛛丝），骨头/蛛丝能参与合成（弓、箭、骨粉催熟作物）
- 简单 A* 寻路（网格上，限制搜索范围）、击退、受击无敌帧、刷新与远距离消失规则

**界面**
- 主菜单（新建世界可填种子、继续世界、设置）
- 暂停菜单、设置（视距、FOV、鼠标灵敏度、音量）
- HUD：准星、生命、饥饿、氧气、快捷栏、护甲值
- F3 调试面板：FPS、坐标、区块、群系、光照值、朝向

**存档**
- 自动保存 + 退出保存：种子、被修改过的区块、玩家状态、背包、容器内容、世界时间
- 存档带格式版本号；读到旧版本存档时能迁移，迁移不了就提示并新建，不崩溃

**合成表**
- 配方由你按品类直觉自行设计（木头→木板→木棍→工具，石头熔炼等），集中定义在数据文件里，并自动生成到 README 的合成表

### 3.2 明确不做（Out of Scope）
另一个维度/地狱、终末维度和 Boss、传送类物品、红石/电路、附魔、酿造、村民与交易（村庄只做建筑和箱子）、其他结构（地牢、神殿、要塞等）、多人联机、成就、命令系统、模组支持。
**遇到范围外的需求，记录到 DECISIONS.md 并跳过，不要自行扩张范围。**

## 4. 画面要求（验收会重点看）

- 统一的原创像素调色板，所有贴图风格一致；方块贴图要有明暗纹理，不能是纯色块
- 平滑光照 + 顶点环境光遮蔽（AO）
- 树叶 alpha 镂空、水和玻璃半透明且排序正确
- 雾、天空、光照随昼夜平滑过渡；夜晚确实暗、火把确实有用
- 粒子：挖掘、破坏、落水
- 性能：面剔除或贪心网格；网格构建在 Worker 中完成，主线程只做上传
  - 目标：视距 8 区块，在有真实 GPU 的机器上稳定 ≥55 FPS
  - **可在无头环境实测的替代指标**（必须测、必须写进 PROGRESS.md）：单区块生成 + 网格构建耗时、视距 8 下的 draw call 数和三角形数、主线程每帧 JS 耗时（不含 GPU）< 8ms、移动穿越区块时主线程最长单帧 JS 耗时
  - 软件渲染下的 FPS 只作参考，不作为验收依据；如果运行环境有真实 GPU，就补测真实 FPS
